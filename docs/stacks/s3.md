# S3 stack

[Back to README](../../README.md)

<img src="../icons/s3.svg" width="48" alt="Amazon S3">

Source: [`s3/`](../../s3)

Creates a private S3 bucket with every form of public access blocked.

## Resources

| File | Resource | Description |
|---|---|---|
| `main.tf` | `aws_s3_bucket.main` | Bucket named `<bucket_prefix><unique suffix>` |
| `main.tf` | `aws_s3_bucket_public_access_block.main` | Blocks public ACLs and public bucket policies |

## Variables

| Variable | Default | Description |
|---|---|---|
| `aws_region` | `us-east-1` | Region where resources are created |
| `bucket_prefix` | `learn-terraform-` | Bucket name prefix; AWS appends a unique suffix |

## Outputs

| Output | Description |
|---|---|
| `bucket_name` | Full name of the created bucket |

## Testing

Upload a file and list the bucket contents:

```bash
cd s3
echo "hello" > test.txt
aws s3 cp test.txt s3://$(terraform output -raw bucket_name)/
aws s3 ls s3://$(terraform output -raw bucket_name)/
```

## Notes

- `terraform destroy` fails if the bucket is not empty. Empty it first:

  ```bash
  aws s3 rm s3://$(terraform output -raw bucket_name) --recursive
  ```

- Objects are encrypted at rest by default (SSE-S3). Versioning is not enabled.
